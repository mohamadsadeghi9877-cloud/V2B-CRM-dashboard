# غرفه‌یار (Ghofreyar) — دستیار صوتی هوشمند غرفه نمایشگاه

پروژه «غرفه‌یار» یک عامل صوتی هوشمند، محلی و آفلاین برای غرفه‌های نمایشگاهی است. این عامل به بازدیدکنندگان سلام و خوش‌آمد می‌گوید، مکالمه‌ای گرم، صمیمی و طبیعی برقرار می‌کند، رفتارهای شوخ‌طبعانه و خارج از موضوع را هوشمندانه مدیریت می‌کند و اطلاعات تماس و نیازهای بازدیدکننده را در یک فرم ساختاریافته به صورت بلادرنگ گردآوری می‌نماید.

---

## 🛠️ پشته فناوری (Tech Stack)

- **بک‌اند**: پایتون ۳.۱۲ با ابزار سریع `uv` برای مدیریت وابستگی‌ها و محیط مجازی
- **STT (تبدیل گفتار به متن)**: کتابخانه `Diba-STT` با مدل پیشرفته `fa` (حجم ۱.۶ گیگابایت) برای بالاترین دقت رونویسی فارسی به صورت محلی و آفلاین روی CPU
- **TTS (تبدیل متن به گفتار)**: کتابخانه `persian-speech` مبتنی بر مدل عصبی `Mana-Persian-Piper` (تولید ۲۵ برابر سریع‌تر از زمان واقعی روی CPU، کاملاً آفلاین)
- **LLM (مغز پردازشی)**: سرور محلی Ollama با مدل‌های متن‌باز فهم فارسی مانند `qwen2:7b` یا `llama3:8b` (بدون هزینه API و بدون وابستگی به اینترنت)
- **فرانت‌اند**: رابط وب ریسپانسیو و زیبا با HTML5 / CSS3 / Modern JavaScript طراحی‌شده برای مانیتورهای بزرگ غرفه نمایشگاهی:
  - رونویسی زنده و حباب‌های گفتگوی صوتی
  - پر شدن بلادرنگ فیلدهای فرم همراه با انیمیشن‌های هایلایت
  - نوار پیشرفت تکمیل اطلاعات (الزامی و اختیاری)
  - ضبط زنده صدا از میکروفون مرورگر و ورودی متنی جایگزین
  - صفحه و کارت تأیید نهایی لید برای ثبت اطلاعات در سیستم غرفه

## 🚀 راهنمای راه‌اندازی و اجرا

### ۱. پیش‌نیازها
- پایتون ۳.۱۲ یا بالاتر
- ابزار `uv` (`pip install uv`)
- سرور [Ollama](https://ollama.ai/) به صورت محلی در حال اجرا با مدل مورد نظر:
  ```bash
  ollama run qwen2:7b
  # یا
  ollama run llama3:8b
  ```

### ۲. نصب وابستگی‌ها با uv
در ریشه پروژه دستور زیر را اجرا کنید:
```bash
python -m uv sync
```

### ۳. اجرای برنامه
سرور وب و رابط غرفه را با دستور زیر اجرا کنید:
```bash
python -m uv run python -m ghofreyar.app
# یا
python -m uv run uvicorn backend.app:app --host 0.0.0.0 --port 8090 --reload
```
سپس مرورگر را در آدرس زیر باز کنید:
👉 **http://localhost:8090**
